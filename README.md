# Курсоград — образовательный портал

Учебный сайт на Flask + SQLite (не магазин): онлайн-курсы, запись, уроки, прогресс.

## Запуск
```bash
pip install -r requirements.txt
python app.py   # http://localhost:8080
```

## Страницы
Главная `/`, Курсы `/courses`, Курс `/course/<id>`, Урок `/lesson/<id>`,
Преподаватели `/teachers`, Регистрация `/register`, Вход `/login`,
Личный кабинет `/dashboard`, О портале `/about`, Контакты `/contacts`, 404.

## База данных
SQLite `data/app.db`: `users`, `teachers`, `courses`, `lessons`,
`enrollments`, `progress`, `feedback`, `messages`.
Пароли — хеши (werkzeug), авторизация — сессии Flask, доступ к урокам и
кабинету — декоратор `@login_required`.

## Стартовые данные
Преподаватели, курсы и тексты уроков лежат в `seed.py` и загружаются при первом
запуске. Если база уже создана старой версией (уроки с текстом-заглушкой),
`init_db()` при старте подставит полноценные материалы, не трогая прогресс
студентов.

Текст урока хранится в лёгкой разметке, которую разбирает фильтр `lesson_html`
в `app.py`: пустая строка — новый абзац, `## Заголовок` — раздел, `- ` и `1. ` —
списки, блок в тройных обратных кавычках — код, `` `код` `` и `**выделение**`
внутри строк. Весь текст экранируется — HTML из базы в страницу не попадает.
